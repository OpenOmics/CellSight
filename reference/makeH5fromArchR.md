# Make h5 object from ArchR data

Make h5 object from ArchR data

## Usage

``` r
makeH5fromArchR(obj, sc1meta, filename, assay)
```

## Arguments

- obj:

  input ArchR object

- sc1meta:

  data.table of cell metadata

- filename:

  filename of output h5 file

- assay:

  assay in ArchR object to use

## Value

h5 object
